# Deeplearning_Weatherfocas
1. Chuẩn bị môi trường
2. Thư mục dự án: Đảm bảo bạn có thư mục Weatherfocas chứa:
weather_app.py (backend Flask).
index.html (frontend React).
Môi trường ảo .venv.
Python: Yêu cầu Python 3.8-3.11.
Node.js: Để chạy serve cho frontend.
3. chạy lệnh môi trường: .venv\Scripts\activate
Thấy (.venv) trước dấu nhắc.
4. Cài thư viện Python:
pip install requests numpy flask flask-cors tensorflow scikit-learn h5py
5. Cài serve cho frontend:
npm install -g serve
6. python weather_app.py
Thấy dòng này là ok : * Running on http://127.0.0.1:5000.
7. sau đó chạy file index.html
